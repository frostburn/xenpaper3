# Xenpaper development

- Always use helpers from `xen-dev-utils` when an appropriate helper is available instead of implementing a local equivalent.
- Keep UI copy functional and minimal. Do not spontaneously add taglines, slogans, promotional prose, decorative labels, eyebrows, badges, or redundant explanatory text. Add visible copy only when the user requests it or it is needed to identify a control, explain required syntax, report an error, or confirm an action. Use plain, concise wording; avoid lines such as "One clip. A whole musical idea."
